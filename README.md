# Skystore

Skystore - это веб-приложение для хранения и продажи плагинов и примеров кода.

## Описание

Skystore предоставляет удобный сервис для хранения ваших плагинов и примеров кода, которые вы хотите продать. Платформа включает в себя каталог продуктов и страницу контактов с возможностью связи с администрацией.

## Особенности

- Каталог продуктов с описанием и ценами
- Страница контактов с формой обратной связи
- Адаптивный дизайн на Bootstrap
- Поддержка Django 4.0+
